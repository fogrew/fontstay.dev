# font-sources

Pickers that download one font style from an open font service. `SourcePicker` is the shared
list, search, style and subset UI; a `FontSource` supplies the catalog and the download.

- Google Fonts: `data/google-catalog.json` is generated by `pnpm google-fonts:catalog` from
  `https://fonts.google.com/metadata/fonts` (open source families, by popularity). `downloadFont`
  fetches the css2 stylesheet from `fonts.googleapis.com`, picks the file of the chosen subset
  and downloads it from `fonts.gstatic.com`.
- Fontsource: `data/fontsource-catalog.json` is generated by `pnpm fontsource:catalog` from
  `https://api.fontsource.org/v1/fonts` (only the non-Google fonts, `type: other`). The file is
  fetched from `cdn.jsdelivr.net/fontsource/fonts/` with an id, subset and style built from
  validated parts.

Catalogs are loaded lazily when a picker is first opened. Downloads check the https host and
path, are size bounded and time out after 15 s. The file then goes through the normal upload
path, so it is validated like any file. These three origins are the only network access in the
app and are listed in `connect-src` (see `docs/security.md`).
