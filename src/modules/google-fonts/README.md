# google-fonts

Google Fonts picker. `data/catalog.json` is generated by `pnpm google-fonts:catalog`
from `https://fonts.google.com/metadata/fonts` (open source families only, sorted by
popularity) and loaded lazily when the picker is first opened. `downloadFont` fetches the
css2 stylesheet for one style from `fonts.googleapis.com`, picks the file of the chosen
subset and downloads it from `fonts.gstatic.com` (https and host checked, size bounded,
15 s timeout). The font goes through the normal upload path, so it is validated like any
file. These two origins are the only network access in the app and are listed in
`connect-src` (see `docs/security.md`).
