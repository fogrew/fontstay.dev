# pwa

Offline use and updates. `scripts/pwa/build-pwa.mjs` runs after `astro build`: it lists every file in `dist/`, hashes them into a build id and writes `dist/sw.js` (from `sw.template.js`) and `dist/version.json`. The worker precaches everything on install and serves it cache first, so the app, the font parser worker and the lazy chunks work offline. A new worker waits instead of taking over: `PwaManager` shows a toast with Update and a changelog link, the new files are already cached in the background, and the next start uses them. After an update the first start shows a toast linking to the changelog since the version the user had (`?since=<version>`). `InstallButton` offers the install prompt where the browser provides one.
