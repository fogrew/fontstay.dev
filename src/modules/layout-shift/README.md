# layout-shift

`predictViewport` (lib/predict.ts) is the live estimate: a small layout model of the sample page (`lib/document.ts`) with greedy line breaking from glyph advances (size-adjust, letter and word spacing applied), Chrome-style rounded line heights from ascent, descent and line gap (overrides scaled by size-adjust), margin collapsing, and the score below. It needs no installed fonts, so it covers every fallback of every system and powers `Optimize for CLS`. It ignores kerning, ligatures and shaping; the e2e test `layout-model.spec.ts` checks it against the browser (scores within 0.02 for a good fit, 0.05 for a bad one). `simulateLayoutShift` below remains as "Verify on this device".

Estimates the layout shift a font swap causes. `layoutShiftScore` follows the Layout Instability definition: elements whose top-left moved (half a pixel or more) are unstable; the impact fraction is the union of their before and after regions clipped to the viewport over the viewport area, the distance fraction is the largest horizontal or vertical move over the larger viewport dimension, and the score is their product.

`simulateLayoutShift` renders a sample document in a hidden, sandboxed same-origin iframe per viewport (412×823 and 1350×940, the Lighthouse mobile and desktop emulation sizes), first with the generated fallback fonts only and then with the uploaded web font, and scores the difference; it also reports line counts, document height and elements whose line breaks changed. The fallback `local()` fonts are the ones installed on the user's device, so the result reflects this device. The iframe styles are applied through `adoptedStyleSheets` to stay within the CSP. `LayoutShiftPanel` reruns the simulation debounced to an animation frame, aborts stale runs and announces results only after they settle.

Known simplification: the distance fraction uses the full movement of an element, not the movement of its visible part.

`createSimulation` keeps one hidden frame per viewport open: the web-font state is measured once, and `measure(fontFaces, spacing)` re-measures the fallback state for new descriptor values and spacing. `compassSearch` (`lib/optimize.ts`) is the deterministic, bounded optimizer behind "Optimize for CLS": a compass search over the free dimensions (size-adjust, the three vertical overrides, letter and word spacing), ordered coordinate by coordinate with step halving, a tiny penalty for moving away from the start, and limits on measurements (150), time (12 s) and abort. Pinned dimensions are never evaluated at another value. It minimizes the sum of the scores over the viewports using the fallback font installed on this device; if the selected font is missing locally the run reports it instead of applying values. The spacing is applied through a `.fonts-loading` class (CSS plus a Font Loading API snippet generated by the generator).
